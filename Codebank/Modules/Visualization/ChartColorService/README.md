# Visualization/ChartColorService

차트 항목에 서로 다른 색상을 순차적으로 할당하기 위한 모듈이다.

## 복사 대상

`src` 폴더 아래의 모든 파일을 복사한다.

## 의존성

- `System.Windows.Media.Color`를 사용한다.
- .NET 8 대상은 WPF 참조를 위해 `net8.0-windows`를 사용한다.

## 참고 사항

- 첫 고정 색상은 빨강 `#FFF21818`이다.
- 현재 존재하는 항목 수를 다음 인덱스로 보고 `0~9`까지는 빨강, 주황, 노랑, 연두, 초록-청록, 하늘, 파랑, 남색, 보라 계열의 고정 색상을 순서대로 반환한다.
- `10`번째 이후 색상부터는 기존 HSV 기반 생성 로직으로 넘어간다.
- fallback 색상은 현재 사용 중인 색과 너무 비슷하지 않도록 계산한다.
- 삭제나 사용자 수동 색 변경이 있어도 고정 색상 구간은 실제 사용 색이 아니라 항목 수를 기준으로 동작한다.
- `IColoredItem`은 `Color` 읽기 속성만 필요하다.

## 동작 요약

- 입력은 `existingItems` 컬렉션 하나를 받는다.
- 다음 색상 인덱스는 `existingItems.Count`로 판단한다.
- `Count`가 `0~9`이면 고정 팔레트 10색을 순서대로 반환한다.
- `Count`가 `10` 이상이면 고정 팔레트를 더 쓰지 않고 자동 색상 생성으로 넘어간다.
- 자동 생성 구간에서는 현재 사용 중인 색과 너무 비슷하지 않은 색을 계산해서 반환한다.
- 고정 팔레트 구간은 실제 사용 색 충돌 여부보다 `Count`를 우선한다.
